## Goal and binding design

Maintain one current navigation index per WORKING, REVIEW and DELIVERABLES zone without treating an index as a business document or inventing acceptance. Dropbox remains canonical. Reuse the document request admission, durable recovery, execution journal and provider conditional operations. No new service, dependency, database or production test project.

The existing `00-CURRENT-INDEX.md` is retained when present to preserve links; otherwise use `00-CURRENT.md`. If both exist, reject adoption as a naming conflict rather than delete either. Package `CURRENT.md` is a separate package index, not a duplicate zone index; link it only when proven valid. Identity is `(project_id, zone)`, not the shared basename. Old index bytes and their exact source identity are preserved before replacement.

Public operation: `navigation.reconcile`, document-request identity, zone, expected_project_revision, expected_generation, expected_index (absent or exact basename/object_id/revision_token/content_sha256), created_at. No client-provided rendered content, document inventory, rules, or approval claim. An existing governed index uses its saved identity; untracked index adoption requires the exact observed identity. Fresh admission is mandatory; retries follow frozen server intention, not a fresh meaning under the same request ID.

Canonical sources are managed document heads and exact versions, existing canonical artifact references, and finalized package references. Unknown physical files are not silently called accepted/current; coverage gaps stay explicit. Zone membership follows actual active stage references. Validate path isolation and physical presence before publishing a link. Never reconstruct project business direction from the old index prose.

Navigation receives its own receipt/evidence shape, not `published:true` or a fake document version. Preserve source snapshot, frozen generation input, generated bytes, conditional write result and postcheck evidence in existing canonical execution storage. `committed` remains distinct from physically verified `finalized`.

Preserved old index bytes are human-readable under server-derived `ARCHIVES/NAVIGATION/<ZONE>/<generation>-<hash>.md`, create-only with exact replay verification; the execution journal references that archive. The visible index itself stays at its original path and is replaced conditionally, never deleted blindly.
